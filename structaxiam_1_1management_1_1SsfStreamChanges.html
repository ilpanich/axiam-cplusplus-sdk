Detailed Description

The changes the change-taking form SsfStream::to_input(const SsfStreamChanges&) applies over a read (CONTRACT.md §32.2, contract 1.62).

Every member is optional: a disengaged member leaves what was read as it is.

A member that can be "none" is a doubly optional value: disengaged is "no change", and engaged-with-std::nullopt is an assigned null, which sets it to none – the key is omitted from the body and null is never sent (§27.11 rule 5; on an update an omitted member takes its default, which for these is null).
