Detailed Description

Emitted when ssf::SsfReceiver::poll (§32.7) returns normally leaving at least one SET unjudged (§19.1, contract 1.60 SHOULD; §34.2 P1).

An unjudged SET is not an error the caller sees: poll() returns, and the transmitter offers the SET again. Without this event a JWKS or replay-store outage is invisible until the backlog grows. Counts only: no jti, no SET. One event per failure category present in the batch.
