Detailed Description

The network.segments[] spec (CONTRACT.md §27.6.2 item 1), for an entity of kind NetworkSegment.

The natural key is site + kind + name, where kind is the wire spelling – "access" or "quarantine", the value create_segment writes and every segment read returns. There is no other spelling here and no mapping to one: zones is a path segment of the server's resource tree, not a kind. The three are the key and so are never drift (§36.3 rule 4); every other member is a field, reconciled by §27.6 rule 3.
