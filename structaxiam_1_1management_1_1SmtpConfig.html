Detailed Description

SMTP-specific configuration.

password is write-only (D-01): #[serde(skip_serializing)] means it is never emitted in a GET/serialized response. On the write path (D-02), #[serde(default)] lets a caller omit the field entirely (deserializing to ""); an empty string is the sentinel for "no new secret supplied — preserve whatever is already stored" (see SurrealEmailConfigRepository:: set_org_config). A non-empty value is a real secret to encrypt+replace.
