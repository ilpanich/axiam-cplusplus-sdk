Detailed Description

409 Conflict on the management surface – §27.4 rule 7.

Derives from AuthzError because §2 already maps 409 there as a resource-level refusal; rule 7 KEEPS that mapping rather than moving it.

const std::optional< std::string > & axiam::management::ConflictError::reason_code ( ) const
inlinenoexcept

The 409 body's reason_code (§36.4, contract 1.62): which of the server's conflicts this is – stale_version, strands_profile, has_children, site_gone, duplicate_name, duplicate_vlan, duplicate_rank, profile_exists, other on the network operations.

Branch on this, never on what(), which carries text for a human. The vocabulary is open: a value this SDK does not know is returned verbatim. std::nullopt when the body had none (a server before 1.1.0, or an operation that does not name one).
