◆ user_code

std::string axiam::DeviceAuthorization::user_code

The code the USER types.

Not wrapped — §14.5 is explicit that wrapping it would defeat the one thing it exists for. It still must not be logged; displaying it is the caller's job.

Embeds the user code so a device that can render a QR code does not make the user type anything.
