Detailed Description

Machine identities, their secrets, and the certificate a device-bound one authenticates with.

The service_accounts namespace handle (§27.2), reached as client.management().service_accounts(). §27.3's C++ row is client.service_accounts().rotate_secret(id) – a method returning a handle, snake_case – and that is what this is.

Every method goes through the one shared transport, so §3 CSRF, the §4 cookie jar, the §5 tenant header, §6 TLS, §16 retry and §19 telemetry apply without this class doing anything to opt in (§27.8).
