Detailed Description

A tenant's network segments and the RADIUS reply profile each owns (RADIUS Live profile): a segment is a node of the reserved /network subtree of the resource tree (kind, VLAN, Filter-Id envelope, placement rank), and its profile is the typed axiam-radius-reply/1 record a decision renders.

Every write is conditional on the version the caller read and passes the server's write gate. The tenant's Session-Timeout cap is one more row of it (get_policy, replace_policy): lowering it is always allowed, raising it is allowed and audited. The decision route FreeRADIUS calls is not in this registry.

The network namespace handle (§27.2), reached as client.management().network(). §27.3's C++ row is client.service_accounts().rotate_secret(id) – a method returning a handle, snake_case – and that is what this is.

Every method goes through the one shared transport, so §3 CSRF, the §4 cookie jar, the §5 tenant header, §6 TLS, §16 retry and §19 telemetry apply without this class doing anything to opt in (§27.8).
