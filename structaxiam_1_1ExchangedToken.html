Detailed Description

POST /oauth2/token with the RFC 8693 grant (§15.1) — a NARROWER token.

There is no refresh-token member, and §15.2 rule 4 makes that structural rather than incidental: an exchange only ever narrows, and a refresh token would let the holder re-widen later. Re-run the exchange for a fresh one.
