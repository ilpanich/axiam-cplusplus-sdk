Detailed Description

The validated claims of an ID token (§12.4).

Present on a token set only when the response carried an id_token AND every §12.4 rule passed.

std::string axiam::IdTokenClaims::raw_claims_json

Every claim the server sent, as raw JSON text.

§12.1 requires SDKs to PRESERVE claims beyond the named ones and forbids rejecting unknown ones — the ID token's full claim set is not enumerated by openapi.json. This is the language-idiomatic open map's stand-in for a header that does not want a JSON type in its public surface.
