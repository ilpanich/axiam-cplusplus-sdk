1023 // ---- §27.2/§27.3: the namespace handles, directly on the client ----
1024 //
1025 // `client.roles().list()`, `client.service_accounts().rotate_secret(id)` — the
1026 // form §27.3's C++ row shows. `management()` above reaches the same handles behind
1027 // one accessor (§27.2 rule 4), and these forward to it, so the two are equivalent
1028 // by construction rather than by two code paths agreeing to stay that way.
1029 //
1030 // Acquiring one performs no I/O beyond the open-client check every accessor makes
1031 // (§27.2 rule 1), and none is constructible without a client (rule 3) — the handle
1032 // constructors take a transport nothing outside this library can build.
1033 //
1034 // Declared, not defined, here: the definitions live in the generated
