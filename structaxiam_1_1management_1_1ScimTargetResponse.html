Detailed Description

A registered SCIM target, as the management API returns it.

The credential is never returned, and there is no member that says anything about it.

The replacement body for scim_targets.update holding every member of this read.

credential is absent: no read carries it, and absent keeps the stored one – unless the update moves the URL (§31.3 rule 2). expected_updated_at is this read's updated_at, so the update is refused 409 if another write landed since (§31.3 rule 4, contract 1.60); reset it to send an unconditional replacement.
