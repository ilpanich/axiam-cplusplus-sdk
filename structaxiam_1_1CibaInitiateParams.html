Detailed Description

Arguments to Client::ciba_initiate() (§33.2 CibaInitiateRequest).

binding_message and login_hint can be personal data: this SDK never logs them. user_code, login_hint_token and request_uri are not members — AXIAM refuses each (§33.3 rule 3).
