Detailed Description

The UpdateScopeRequest schema from the server's OpenAPI document.

Every member is optional, so this is a SPARSE body: an engaged std::optional is sent and a disengaged one is OMITTED from the request entirely, rather than sent as null (§27.4 rule 5). On a sparse update those say opposite things, and only omission means "leave it alone".
