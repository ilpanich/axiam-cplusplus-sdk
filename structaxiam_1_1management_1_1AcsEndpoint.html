Detailed Description

One AssertionConsumerService endpoint of a service provider.

The list of these is an allow-list, checked the way OAuth2 redirect URIs are: an AuthnRequest naming an ACS URL is honoured only when the URL equals one registered here, byte for byte. No globs, no prefix match.
