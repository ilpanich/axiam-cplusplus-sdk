Detailed Description

template<typename T>
struct axiam::management::Page< T >

One page of a paginated response (§27.4 rule 4).

total is the SERVER's count across every page. It is NOT items.size(), and deriving one from the other is how a management tool silently processes the first fifty of four hundred rows – so they are separate members and neither is computed from the other.

A bare JSON array response is NOT a page and is never modelled as one; those operations return a plain std::vector.
