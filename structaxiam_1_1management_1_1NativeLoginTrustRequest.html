Detailed Description

Native sign-in trust (G-A): which ID tokens this provider issued to an app are accepted as a sign-in at the token endpoint.

Mirrors the domain block on the wire, as TokenExchangeTrustRequest does, so an omitted member takes its documented default rather than failing deserialization. Only an OidcConnect provider may enable it.

Every member is optional, so this is a SPARSE body: an engaged std::optional is sent and a disengaged one is OMITTED from the request entirely, rather than sent as null (§27.4 rule 5). On a sparse update those say opposite things, and only omission means "leave it alone".

◆ client_ids

std::optional<std::vector<std::string> > axiam::management::NativeLoginTrustRequest::client_ids = std::nullopt

The audiences a presented ID token may carry: the iOS bundle ID, Android client ID or Apple app ID the native SDK was configured with.

Required (non-empty) when enabled; at most 64 entries of at most 512 characters, none blank, none repeated. The web client_id is accepted only when it is listed here. Optional.
