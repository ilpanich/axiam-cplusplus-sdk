Detailed Description

Per-call override of the {org_id}/{tenant_id} a route substitutes (§27.4 rule 3).

Applied with a handle's in_org() / for_tenant(), which return a NEW handle rather than mutating the one you called them on. An administrator holding a handle to their own tenant should not find it repointed at someone else's because an unrelated code path re-scoped a shared object – and on a management surface that failure mode WRITES to the wrong tenant.
