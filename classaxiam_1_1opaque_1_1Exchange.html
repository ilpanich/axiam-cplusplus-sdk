Detailed Description

One in-flight exchange, owning a native state handle.

The handle is single-use: the library consumes it in finish whether that succeeds or fails. This class takes it out of a one-shot slot, so a second finish throws rather than handing a dangling pointer across the ABI.

The destructor releases an exchange the caller abandoned — a login started and never completed. Which release to call is decided by a flag set at construction rather than by a virtual, because a destructor cannot dispatch into a subclass whose own storage has already been torn down.

void axiam::opaque::Exchange::close ( )

Releases the exchange if it was never finished.

Idempotent, and a no-op once finish has spent the handle. Calling it is optional — the destructor does the same thing — but an application that knows the exchange is over should not wait for a scope to end.
