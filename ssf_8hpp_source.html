1// §32.7 The SSF receiver helper — verify a Security Event Token, and poll.
2//
3// AXIAM is a Shared Signals Framework transmitter (CONTRACT.md §32): it sends
4// CAEP and RISC security events as Security Event Tokens (RFC 8417) to the
5// relying parties a tenant administrator registered with the §27 `ssf`
6// namespace. This header is for the RELYING PARTY that receives them — a
7// different audience from that namespace:
8//
9// * SsfReceiver::verify_set() verifies one compact SET, pushed to your endpoint
10// (RFC 8935) or returned by a poll, in the contract's fixed order, and refuses
11// at the first failure with a SetVerificationError naming the step.
12// * SsfReceiver::poll() calls the stream's RFC 8936 poll endpoint, verifies
13// every SET it returns and hands back the verified and the refused apart.
14//
15// Neither transmits, signs or registers anything, and neither trusts a key it
16// did not fetch from the configured JWKS: no `jwk` or `x5c` header member is
17// ever honoured (§32.9).
